> **"The goal isn't memorizing solutions — it's developing the spatial and logical intuition to solve any arbitrary boundary condition."**

This repository contains my **200+ LeetCode solutions** organized by topic category. I follow a **Graph-First Dual-Track** approach — learning new advanced patterns (Track A) while continuously revising foundational topics (Track B) in parallel.

**Every solution includes:**
- Clean, optimized C++ implementation
- Time & space complexity analysis
- Pattern recognition notes

## 🧭 180-Day Graph-First Curriculum

I follow a structured **180-day DSA roadmap** with a Graph-First approach:

| Phase | Days | Focus |
|:---|:---:|:---|
| **Phase 0** | 1–30 | Graphs — BFS/DFS, Cycles, Topo Sort, Shortest Paths, MST, DSU, SCC |
| **Phase 1** | 31–45 | Heaps & Advanced BST — Priority Queues, K-Way Merge, Two Heaps |
| **Phase 2** | 46–60 | Greedy & Backtracking — Intervals, N-Queens, Subsets |
| **Phase 3** | 61–100 | Dynamic Programming — 1D/2D, Knapsack, LIS, Tree DP, Bitmask |
| **Phase 4** | 101–115 | Tries, Bit Manipulation & Advanced Graphs |
| **Phase 5** | 116–130 | Segment Tree, Fenwick, KMP, Rabin-Karp, LRU/LFU |
| **Phase 6** | 131–140 | Math & Number Theory |
| **Phase 7** | 141–155 | Array/String Pattern Repair & Sorting |
| **Phase 8** | 156–170 | Striver SDE Interview Validation |
| **Phase 9** | 171–180 | Final Mocks & Weakness Repair |

### Daily Execution
- **Track A (60–90 min):** New topic theory → dry run → C++ implementation → core problems
- **Track B (25–40 min):** Rotating revision of foundational topics with fresh problems
